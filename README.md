# AMAL_AI
An multilingual RAG LLM chatbot.

To run Fast API backend locally:
1. cd backend
2. Create a python virtual enviorment (Mac/Linux: python3 -m venv venv, Windows: python3 -m venv venv) ~ Only needs to be done once
3. Activate (Mac/Linux:  source venv/bin/activate, Windows: venv\Scripts\activate)
2. pip3 install -r requirements.txt
3. python3 run.py
